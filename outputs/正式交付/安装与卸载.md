# 安装与卸载

版本：1.0.0-rc1，2026-10-17。默认使用 **Release**，这是待实机验收的日用候选版。

1. 退出游戏，在 HD2 Mod Manager 中停用所有旧 C4 包，包括参考版、M1、观察包、路线 A、M1.2、M1.3。
2. 保留 Bingus Shared Loader v17 或更新版本，导入 `C4快速引爆-1.0.0-rc1-Release.zip`，启用并部署。
3. 使用默认鼠标绑定：游戏 Fire 为鼠标左键，右键由本包接管。自定义键位尚未支持。
4. 拿出 C4，等待装备完成并松开左右键一次；之后左键投掷、右键引爆。模式若是 DETONATE，包会在当前实例空闲且双键松开时自动校正为 DEPLOY，无需每次手动切菜单。菜单改模式、重新拾取或重生后同样需要这一释放基线。

自动校正只在空闲时进行；若拿出 C4 时一直按住左键，校正尚未发生，游戏仍可能按原模式处理左键。请先松键完成接管。本包不会补发校正期间的点击。

空闲站立时，右键走原生引爆动作以取得按压反馈；投掷收尾/装填等忙碌状态走直接引爆，以保留快速操作。后一路目前没有额外按压动画。两路不会由本包为同一个请求同时调用。

切入、切出 C4 的装备过渡阶段暂停接管并取消尚未提交的右键；重新拿稳且双键松开后恢复。不支持载具内操作。原生动作已经提交后产生的爆炸不能通过随后切枪撤回。

发生兼容性或动作结果不确定的故障时，本次加载停止引爆接管并尝试释放自有右键限制，不会自动重试。退出后检查 `C:/Users/zj/AppData/Local/CowboyBingus/Helldivers2/Logs/C4QuickRelease_part*.log` 的一次性故障记录。

卸载：退出游戏，在 HD2 Mod Manager 中停用本包并重新部署。没有向旧武器实体回写恢复值；实例模式经游戏自身保存的可能性尚待实机检查，停用后如需更改模式可使用原游戏菜单。

`诊断构建` 子目录只供具体问题复查，和 Release 使用同一 Mod GUID、同一全局哨兵，必须二选一。普通验收先用 Release；不要把两包一起导入启用。诊断日志为 `C4QuickDiagnostic_part*.log`，包含阶段统计，会增加开销。

本次只生成交付文件，未替换当前游戏部署。联机、长期弹药一致性及实际性能尚未验证。
